Escribir un artículo

Rellena el título, escribe el texto y, si quieres, añade una foto. No necesitas usar Google Drive.

Puedes pegar texto directamente desde Word. Para añadir una foto dentro del texto, pulsa «📷 Foto».

Selecciona la foto desde el escritorio, la carpeta de imágenes o el móvil. Máximo 3 MB por imagen.
